What I’ve built

ArcOS — a compound-AI engine

Architect & sole engineer · 2025–present

A five-stage pipeline — perceive → decide → assemble → generate → remember — on one principle: perception is delegated to the language model, while control, persona, and routing live in deterministic, hard-coded logic (31 decision blocks, asserted in the code). Two of the five stages run no learned weights at all. The result keeps a consistent persona and durable long-term memory across sessions and across underlying models (Gemma, Llama, Qwen) — swapping the backbone is a config change, not a rewrite.

Shipped to production

Web & desktop live · iOS in review

ArcOS runs in production today — on the web and on desktop (macOS, Windows, Linux), with a native iOS app in review. It serves real users for an institutional client I work with under an NDA, so I speak only to the engineering. It has held up through months of real production traffic.

Self-hosted GPU infrastructure

A single NVIDIA H200 · self-hosted

I run the full ArcOS stack myself on a single NVIDIA H200 I self-host in my own backyard — from model serving to deployment — with cooling I built by hand. No data center, no team. Compute you control is half the story; judgment is the other half.
